# Suportes para Defesa

Materiais de apoio para a defesa oral do projeto. Não contém código — apenas documentos e imagens de apresentação.

## 📄 Ficheiros

* **`LaTeX_Relatorio_projeto_Licenciatura_notas_defesa.pdf`** — PDF de apoio com notas para a defesa.
* **`notas defesa.txt`** — Apontamentos soltos para a apresentação (ex: tópicos a abordar sobre um cenário de produção — recolha de dados/estatísticas, aprendizagem ativa — e a conclusão de que o modelo **Multi-Layer Perceptron (MLP)** foi a solução ótima do trabalho).
* **`grafico_teste_cego_anomalias.png`** — Cópia do gráfico de recall por anomalia (ver `../analise_network/modelos/readme.md`) usada nos slides.
* **`camera image.png`**, **`pc image.png`**, **`router image.png`**, **`semaforo image.png`**, **`server image.png`** — Ícones/imagens dos dispositivos usados para ilustrar a topologia da rede (ex: `esquema.pkt`) e a arquitetura da simulação nos slides/relatório.
